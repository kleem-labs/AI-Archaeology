# The Book in Ten Parts

A list of 126 chapters feels like a file index. A book needs a journey. Each
part below ends where a new kind of failure makes the next part necessary.

| Part | Excavations | Human question |
|---|---:|---|
| I — Measuring Reality | 000–005 | How can observations become objects we can compare and transform? |
| II — Inventing Meaning | 006–016 | How can context create meaning, attention, and a Transformer? |
| III — Learning from Error | 017–035 | How can uncertainty and mistakes change a machine? |
| IV — Building a Tiny GPT | 036–045 | How can text become lessons and predictions become generation? |
| V — Making Answers Useful | 046–055 | How do we evaluate, ground, align, and equip a model? |
| VI — Trusting an Acting Machine | 056–065 | What may an agent do, and what proves it succeeded safely? |
| VII — Learning After Deployment | 066–075 | How do systems change, drift, and reveal their inner causes? |
| VIII — Seeing and Creating | 076–085 | How do the same discoveries reach images and generative models? |
| IX — Acting and Scaling | 086–100 | How do rewards, modalities, infrastructure, and governance meet? |
| X — Learning What We Still Do Not Know | 101–125 | How can a system adapt, reason, verify, and research without losing control? |
| XI — Earning the Right to Improve | 126–150 | How can proposed improvements survive experiments, adversaries, oversight, and rollback? |

Start with [Excavation 000](excavations/000-before-mathematics-existed/README.md),
but do not rush to “finish chapters.” Stop whenever a failed attempt surprises
you. That surprise is the excavation.
