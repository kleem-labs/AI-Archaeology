# The Narrative Spine

This is the causal map the prose must enact. It is not a public-facing table of
contents.

## Volume I — We build a mind

| Arc | Excavations | What the same system is trying to do |
|---|---:|---|
| Observe | 000–005 | Recognize animals, compare them, describe change, and build reusable transformations. |
| Infer meaning | 006–016 | Learn meaning from usage, retrieve relevant context, assemble a Transformer, and discover hidden causes behind words. |
| Learn from uncertainty and error | 017–035 | Represent uncertainty, price mistakes, assign responsibility, update weights, and test whether learning survives new cases. |
| Build a language generator | 036–045 | Turn text into visible pieces, preserve order and causality, predict tokens, and close the generation loop. |

## Recurring world

The concrete world grows rather than resets:

```text
valley observations
    → ranger knowledge system
    → language-learning machine
    → tiny assistant
    → deployed field agent
    → multimodal research system
    → bounded self-improving institution
```

Not every chapter must mention a tiger. Every chapter must, however, say what
the evolving system could do before this chapter and which new encounter made
that capability insufficient.
