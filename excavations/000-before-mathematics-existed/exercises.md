# Exercises — Before Mathematics Existed

## Observe

1. Choose an ordinary object and describe it without using its name or category.
2. List twenty observable details. Then keep only five for recognizing another instance. Defend every deletion.
3. Describe two different experiences that exact matching would call different but a person treats as the same kind of event.

## Reason

4. A village records only animal color. Construct two dangerous failures caused by this representation.
5. Explain the difference between compression and useful compression.
6. Can a detail be noise for one task and essential for another? Give three examples.

## Reconstruct

7. Invent a world with no number words. Describe how its people might still compare quantities.
8. Design the smallest memory record that helps someone recognize an approaching storm.
9. Write one paragraph arguing against the claim “all available data should always be preserved.”

## Bridge

10. Turn the five properties from Exercise 2 into repeatable questions. You have just designed the beginning of a feature extractor.
