## Cinematic continuity sequence

Create one continuous five-frame scene—not five unrelated illustrations:

1. **Question:** How can many comparable features travel as one object without losing which is which?
2. **Object:** an ordered leather satchel with one pocket for each tiger feature
3. **Failure:** Loose measurement stones spill together; weight can no longer be distinguished from speed.
4. **Transformation:** The stones slide into named pockets whose order remains fixed for every animal.
5. **Seal:** A vector lets several measurements travel together while their positions preserve meaning.

Keep the same object, lighting, camera direction, and landmarks in every frame. The final frame may reveal notation faintly, but no equation may appear before the physical transformation has made every operation necessary.
