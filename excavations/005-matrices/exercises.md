# Exercises — Matrices

1. Multiply `[[2, 0], [0, 3]]` by `[4, 5]` by hand.
2. What does the identity matrix do to every vector?
3. Construct a matrix that swaps the coordinates of `[x, y]`.
4. Apply two transformations in opposite orders. Do they agree?
5. Run `implementation.py` and add a reflection across the horizontal axis.

## Build

Design a matrix whose rows compute the sum and difference of two input features. Explain each row as a question asked of the input.
