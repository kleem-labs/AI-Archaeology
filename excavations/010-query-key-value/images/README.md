## Cinematic continuity sequence

Create one continuous five-frame scene—not five unrelated illustrations:

1. **Question:** Why must asking, matching, and contributing be three different jobs?
2. **Object:** three masks labeled query, key, and value hanging above one word
3. **Failure:** Using one description for every job confuses what is sought, how relevance is tested, and what information is finally carried.
4. **Transformation:** The word passes through three masks: one asks, one advertises, and one contributes.
5. **Seal:** Query, key, and value separate the question, the match, and the knowledge that travels.

Keep the same object, lighting, camera direction, and landmarks in every frame. The final frame may reveal notation faintly, but no equation may appear before the physical transformation has made every operation necessary.
