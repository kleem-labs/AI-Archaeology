## Cinematic continuity sequence

Create one continuous five-frame scene—not five unrelated illustrations:

1. **Question:** How can a machine use an error to change the internal decisions that produced it?
2. **Object:** a clay brain beside a prediction stone and an error chisel
3. **Failure:** The machine can measure that its answer was wrong but the judgment leaves no mark on its internal weights.
4. **Transformation:** The error chisel travels backward, assigning each adjustable surface a small responsibility and reshaping it.
5. **Seal:** Learning begins when observed error can alter the decisions that created it.

Keep the same object, lighting, camera direction, and landmarks in every frame. The final frame may reveal notation faintly, but no equation may appear before the physical transformation has made every operation necessary.
