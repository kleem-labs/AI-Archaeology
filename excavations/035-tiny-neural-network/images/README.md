## Cinematic continuity sequence

1. **Question:** What fails if we hide everything behind a framework call?
2. **Object:** the tiny neural network lantern mounted on the ring of glass lanterns

5. **Seal:** A Tiny Neural Network keeps the missing power: build a two-layer network, cache its intermediate values, backpropagate every derivative, update on batches, and evaluate on unseen data.
