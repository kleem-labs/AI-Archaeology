# Visual brief

Show an overflowing word dictionary, an excessively long character belt, and repeated fragments snapping into reusable subword tiles. A future animation should expose vocabulary-size versus sequence-length tradeoffs.

## Cinematic continuity sequence

Create one continuous five-frame scene—not five unrelated illustrations:

1. **Question:** What Can a Language Model See?
2. **Object:** the tokenization compass mounted on the sentence-wheel
3. **Failure:** The compass follows the tempting path—give every complete word one ID. Then the evidence answers: spaces appear to provide the boundaries.
4. **Transformation:** The mechanist changes one moving part. The compass can now use characters. Any new spelling can now be represented.
5. **Seal:** Tokenization keeps the missing power: use characters. Any new spelling can now be represented.

Keep the same object, lighting, camera direction, and landmarks in every frame. The final frame may reveal notation faintly, but no equation may appear before the physical transformation has made every operation necessary.
