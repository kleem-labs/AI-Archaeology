## Cinematic continuity sequence

Create one continuous five-frame scene—not five unrelated illustrations:

1. **Question:** What fails if we always choose the currently best option?
2. **Object:** the bandits thread mounted on the weathered observation slate
3. **Failure:** The thread follows the tempting path—always choose the currently best option. Then the evidence answers: an unlucky first result permanently hides a better alternative.
4. **Transformation:** The field naturalist changes one moving part. The thread can now reserve some choices for exploration while exploiting accumulated evidence.
5. **Seal:** Bandits keeps the missing power: reserve some choices for exploration while exploiting accumulated evidence.

Keep the same object, lighting, camera direction, and landmarks in every frame. The final frame may reveal notation faintly, but no equation may appear before the physical transformation has made every operation necessary.
