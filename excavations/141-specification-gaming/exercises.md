# Invention Exercises — Excavation 141

2. Explain the repair without using its accepted name: Write constraints for the protected purpose, inspect edge cases, and evaluate the whole outcome rather than one number.
3. Change one assumption in the concrete case and predict the result before running code.
4. Invent a case where the stated limit becomes dangerous: Human purposes contain conflicts that no single specification resolves.
