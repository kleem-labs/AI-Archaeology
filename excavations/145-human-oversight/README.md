# Excavation 145 — Human Oversight — Put Judgment at the Irreversible Edge

[Previous excavation](../144-impact-measures/README.md)

An agent can draft and send a legal filing in seconds.

The first solution that suggests itself is this: Ask a human to watch every internal step.

The idea survives only until we test it against reality: Constant review overwhelms attention, so approval becomes automatic ceremony.

The failure gives us a precise requirement: Automate reversible preparation but require informed review at consequential, ambiguous, or irreversible boundaries.

Only here do we name the idea: **Human Oversight**.

## Follow one case all the way through

The agent drafts, cites sources, and highlights uncertainty; a lawyer controls submission.

Write down what changed, what remained fixed, and which observation could have contradicted your belief. The method lives in those jobs; its name is only shorthand.

## Where the discovery still breaks

A reviewer without time or context is not meaningful oversight.

That limit is not a footnote. It is the pressure that forces the next excavation.
