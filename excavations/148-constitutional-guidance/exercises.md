# Invention Exercises — Excavation 148

1. Recreate the smallest version of this failure: A novel case has no matching example, and style does not reveal the governing reason.
2. Explain the repair without using its accepted name: Write inspectable principles, use them to critique drafts, revise, and record which principle controlled the change.
3. Change one assumption in the concrete case and predict the result before running code.
4. Invent a case where the stated limit becomes dangerous: Principles conflict and still require legitimate interpretation.
