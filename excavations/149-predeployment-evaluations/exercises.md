# Invention Exercises — Excavation 149

1. Recreate the smallest version of this failure: The first realistic discovery of a dangerous capability harms actual users.
2. Explain the repair without using its accepted name: Test capabilities, misuse paths, safeguards, and operating limits in staged environments before granting authority.
3. Change one assumption in the concrete case and predict the result before running code.
4. Invent a case where the stated limit becomes dangerous: Evaluations sample futures; passing them never proves universal safety.
