# Invention Exercises — Excavation 150

1. Recreate the smallest version of this failure: Contaminated tests, reward hacks, or one lucky run can promote a worse and less controllable successor.
2. Explain the repair without using its accepted name: Separate proposal, sandboxed experiment, reproducibility, independent evaluation, impact review, authorization, staged release, and rollback.
3. Change one assumption in the concrete case and predict the result before running code.
4. Invent a case where the stated limit becomes dangerous: The loop remains only as wise as its objectives, evidence, boundaries, and accountable humans.
