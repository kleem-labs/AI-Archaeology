# Mistakes Worth Preserving — Excavation 201

## The tempting idea

We tried to write each tray as an ordinary list and scan every position whenever membership, overlap, or exclusion is questioned.

## The evidence that refused it

the same animal can occur twice, order pretends to matter, and asking which animals occupy both trays requires a new hand-written loop every time. The list stores a sequence; the question concerns a boundary.

## What the wreckage taught us

The next construction had to treat each tray as a collection whose identity depends on membership rather than order or repetition, then construct overlap by retaining exactly the objects admitted by both boundaries.

Keep this wrong idea. It is the negative space around Sets: it records why the accepted method has exactly the responsibilities it does.
