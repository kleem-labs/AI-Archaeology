# Visual Brief — Functions — A Reusable Promise from Input to Output

Create a two-panel mathematical fantasy scene in the Undercroft of First Principles.

- **Before:** show this concrete problem without symbols: At the vault's next table, each animal card enters a brass slot marked *measured weight*. Tiger enters twice. If the slot returns 220 kg once and 17 kg the next time, downstream comparison becomes impossible.
- **After:** let the geometry of Functions emerge physically from the repaired action: require every allowed input to point to exactly one output, while permitting different inputs to share the same output.
- Preserve the same named objects across both panels so the viewer can see what changed.
- Hide the equation in the stonework as a final caption; it must never replace the visible reasoning.

The image should help a reader reconstruct the discovery from memory, not decorate a page that remains unexplained.
