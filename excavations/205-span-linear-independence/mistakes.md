# Mistakes Worth Preserving — Excavation 205

## The tempting idea

We tried to count every stored direction as a new dimension and assign each one an independent coordinate.

## The evidence that refused it

northeast equals east plus north, so the same displacement receives many coefficient lists. The coordinate system can no longer tell which explanation is unique, and parameter count exaggerates true capacity.

## What the wreckage taught us

The next construction had to call the reachable collection of combinations the span, and call directions independent only when no nontrivial weighted combination collapses to zero.

Keep this wrong idea. It is the negative space around Span and Linear Independence: it records why the accepted method has exactly the responsibilities it does.
