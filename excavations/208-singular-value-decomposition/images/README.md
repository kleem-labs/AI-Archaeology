# Visual Brief — Singular Value Decomposition — The Important Directions of Any Matrix

Create a five-frame mathematical fantasy sequence inside **The Chamber of Directions**.

1. **Question:** Which coordinated channels carry most of this entire transformation?
2. **Object:** show a rectangular brass organ with input grooves and output bells.
3. **Failure:** Polishing the largest rivets changes little; the loudest bell is driven by a pattern spread across many modest parts.
4. **Transformation:** Rotate the input wheel until each independent push rings one output direction, then order the bells from strongest to faintest.
5. **Memory seal:** reveal “SVD separates any matrix into its strongest input-to-output channels.”

Preserve the same named objects, camera direction, and visual landmarks across
all five frames so the viewer experiences one changing world rather than five
illustrations. The formula may appear only as a faint final engraving after the
transformation. The image succeeds when a reader can cover the caption and
reconstruct the mathematical promise from the scene alone.
