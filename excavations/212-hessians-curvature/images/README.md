# Visual Brief — Hessians and Curvature — Why the Same Slope Can Hide Different Valleys

Create a five-frame mathematical fantasy sequence inside **The River of Change**.

1. **Question:** Two places have the same slope—why does one permit a bold step while the other punishes it?
2. **Object:** show two clay valleys and a pair of rolling marbles.
3. **Failure:** Both compasses show the same slope, yet one valley bends gently and the other turns into a narrow wall.
4. **Transformation:** Press a curvature grid into the clay. It records how each component of the gradient changes as every direction moves.
5. **Memory seal:** reveal “A Hessian is a map of how the slope itself bends.”

Preserve the same named objects, camera direction, and visual landmarks across
all five frames so the viewer experiences one changing world rather than five
illustrations. The formula may appear only as a faint final engraving after the
transformation. The image succeeds when a reader can cover the caption and
reconstruct the mathematical promise from the scene alone.
