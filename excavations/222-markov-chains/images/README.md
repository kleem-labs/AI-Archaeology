# Visual Brief — Markov Chains — When the Present Carries the Relevant Past

Create a two-panel mathematical fantasy scene in the Undercroft of First Principles.

- **Before:** show this concrete problem without symbols: A ranger moves among forest, river, and village. Tomorrow's location depends strongly on today's location. The station has years of paths, but planning one step ahead should not require rereading every footprint since the expedition began.
- **After:** let the geometry of Markov Chains emerge physically from the repaired action: choose a state description rich enough that, once the present state is known, earlier history adds no further information about the next-state distribution.
- Preserve the same named objects across both panels so the viewer can see what changed.
- Hide the equation in the stonework as a final caption; it must never replace the visible reasoning.

The image should help a reader reconstruct the discovery from memory, not decorate a page that remains unexplained.
