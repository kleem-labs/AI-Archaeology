# Visual Brief — Numerical Stability — Preserving Mathematics Inside a Finite Machine

Create a five-frame mathematical fantasy sequence inside **The Garden of Futures**.

1. **Question:** How can a finite machine travel to the same mathematical truth without overflowing on the way?
2. **Object:** show a small brass instrument facing three unbearably bright exponential flames.
3. **Failure:** The first flame becomes infinity before the machine can compare it with the others; a meaningful ratio collapses into infinity divided by infinity.
4. **Transformation:** Transpose every score by the largest one. The flames shrink into the instrument's range while their relative brightness remains unchanged; restore the removed scale only at the end.
5. **Memory seal:** reveal “Numerical stability is a safer computational path to the same mathematical truth.”

Preserve the same named objects, camera direction, and visual landmarks across
all five frames so the viewer experiences one changing world rather than five
illustrations. The formula may appear only as a faint final engraving after the
transformation. The image succeeds when a reader can cover the caption and
reconstruct the mathematical promise from the scene alone.
